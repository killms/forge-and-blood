O que estás a ver
  • Backdrop: gradientes CSS puros — zero imagens externas. Quando o MCP do PixelLab estiver activo, trocamos só o background por url('assets/biomes/forest.png').
  • Partículas: 8 elementos animados via @keyframes. Caem folhas (forest), sobem brasas (lava), neve cai (frost), motes flutuam (crypt), poeira dourada (arena).
  • Vignette + darkening: overlay radial garante que os fighters destacam mesmo num cenário colorido.
  • Fighters: usei o teu elf knight (assets/chars/elf-knight-idle.gif, 68×68 PixelLab) + goblin (assets/sprites/imp-sword-idle.gif). Mesmo CSS pixel-perfect do jogo real.
  • Idle bob: os portraits oscilam suavemente como no jogo (animation: idle-bob).
Quando temos os assets reais (PixelLab via MCP)
  • Os gradientes ficam como fallback — se uma imagem falhar a carregar, o gradiente continua a aparecer.
  • Mantemos as partículas. Combinadas com pixel art autêntica, ficam estilo Darkest Dungeon / Ragnarok.
  • Podemos ainda adicionar parallax (sky background + foreground separados) para profundidade.
